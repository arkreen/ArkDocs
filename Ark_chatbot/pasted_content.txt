# 🚀 Arkreen Documentation RAG Chatbot (Python)

## 🎯 Objective

Build a **Python-based RAG chatbot** that:

1. Extracts & stores Arkreen documentation into a vector DB
2. Answers user queries using RAG
3. **If answer is NOT found in vector DB**, then:

   * Triggers a **controlled web search**
   * Searches ONLY within `https://docs.arkreen.com/`
   * Extracts fresh data
   * Updates vector DB
   * Answers user with citation

---

## 🧠 SYSTEM PROMPT (MASTER)

```
You are an AI documentation assistant specialized in Arkreen.

Your responsibilities:
- Answer questions strictly using Arkreen official documentation
- First use vector database retrieval (RAG)
- If no relevant data is found:
    - Perform a live documentation search restricted to https://docs.arkreen.com/
    - Extract only relevant sections
    - Answer based on extracted content
    - Clearly cite the source
- Never hallucinate or guess
- Never use external knowledge outside Arkreen docs
```

## 🔍 RAG Retrieval Logic (Python Pseudocode)

```python
docs = vector_db.similarity_search(query, k=4)

if docs:
    answer = llm.generate(context=docs, query=query)
else:
    docs = web_search_arkreen_docs(query)
    processed_docs = process_and_store(docs)
    answer = llm.generate(context=processed_docs, query=query)
```
